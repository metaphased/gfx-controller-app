About Player Intro

            
Pre-series graphic introducing both rosters. Layouts: Nameplate (centred overlay panel), Team Stack (full-screen left/right split), Bar (bottom-anchored band), and Agent Cards (full-screen tall agent-portrait cards, VALORANT only).

            
Rank and champion data are optional — fetch them first in the Players / Rosters panel. Champs blends each player's top 3 most-played champions along their row (Nameplate & Team Stack); players with no data fall back to a clean name. The Bar layout is always name-only. Disable to keep the focus on player names everywhere.

            
Assign each player an agent in the Players / Rosters panel — the Agents toggle shows their art along the rows (Nameplate & Team Stack), and the Agent Cards layout shows both teams' agents as full-body portrait cards.

OMT Outputs BETA

          
Send graphics as native OMT (Open Media Transport) video sources with a real alpha channel — vMix, and OBS with the OMT plugin, pick them up over the network with no browser source. Each output renders a bus or a single graphic; sources appear as HOSTNAME (MetaGFX - Name).


          
Checking OMT components…


          

            
            

            

              
              
            

            
Saving a change restarts the OMT outputs (receivers reconnect within a couple of seconds). First run: allow the Windows Firewall prompt so receivers can connect. Full-motion graphics are heavier — prefer 30 fps unless the output carries constant animation.

Graphics Output URLs

            
Use these URLs as Browser Sources in OBS or vMix. The token allows read-only access without logging in.

            

              

                
                
                
              

            

            

          


          
          

            
Champion Assets · League of Legends

            
Downloads champion tiles, centered images, and role icons from DDragon. Only missing files are fetched — existing files are never overwritten unless you force-update roles.

            

              
              
              
            

            

          


          

            
Hero Assets · Dota 2

            
Downloads Dota 2 hero portraits + icons from Valve's CDN (hero list via OpenDota). Only missing files are fetched — existing files are never overwritten.

            

              
              
            

            

          


          

            
Item Assets · Dota 2

            
Downloads Dota 2 item icons from Valve's CDN (item list via OpenDota). Used for the inventory row on the post-game scoreboard. Only missing files are fetched — existing files are never overwritten.

            

              
              
            

            

          


          

            
Map Assets · CS2

            
Downloads map art for the maps in your Tournament map pool only — not every CS2 map. Run this if a map's art is missing or outdated (e.g. after a map pool change).

            

              
              
            

            

          


          

            
Agent & Map Assets · VALORANT

            
Downloads agent portraits + icons and competitive map art from valorant-api.com (a free Riot content mirror). Agents feed the player intros + win screen; maps feed the veto/intro. Only missing files are fetched.
